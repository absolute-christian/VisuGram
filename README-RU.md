## 🚀 Быстрый старт

### 1 · Скачай

Забери **ZIP для Windows x64** со страницы [релизов](https://github.com/absolute-christian/VisuGram/releases/tag/visual-preview-5).

### 2 · Распакуй и запусти

Распакуй архив целиком в отдельную папку и запусти **`VisuGram.exe`**. Папку **`TelegramForcePortable`** оставь рядом с программой.

```text
VisuGram/
├── VisuGram.exe
├── TelegramForcePortable/
├── README.txt
├── LICENSE
└── LEGAL
```

### 3 · Настрой под себя

Открой **Мои звёзды → Визуальные звёзды**, чтобы включить визуальные подарки. В **Редактировать профиль** можно указать визуальный номер и юзернеймы.

> [!TIP]
> Для запуска опубликованного ZIP компиляция не нужна. Данные аккаунта хранятся в portable-папке: держи её приватной и сделай резервную копию перед заменой установки.

## 🎨 Визуальный режим

| Где | Что делать |
| :--- | :--- |
| **Мои звёзды** | Включи **Визуальные звёзды**, чтобы отображался бесконечный баланс. |
| **Отправить подарок** | Выбери публичный подарок или коллекционный вариант, добавь подпись и отправь локально. |
| **Избранное** | Выбери себя получателем, чтобы сохранить здесь локальный подарок. |
| **Профиль → Подарки** | Открой локальный подарок, чтобы закрепить, скрыть или удалить его. |
| **Редактировать профиль** | Введи визуальный номер и список коллекционных юзернеймов. |

Для отрисовки используются ресурсы подарков Telegram: коллекционные модели, цвета фона и узоры. Публичный коллекционный подарок также можно загрузить по ссылке **`t.me/nft/...`**.

Выключение визуальных звёзд скрывает локальные подарки, сохраняя коллекцию. Чтобы вернуть отображение исходного номера или юзернеймов аккаунта, очисти соответствующее визуальное поле.

## ❓ FAQ

<details>
<summary><b>Визуальные подарки дают настоящие NFT или звёзды?</b></summary>

Они создают локальную визуальную коллекцию. Реальное владение коллекционными подарками и баланс звёзд определяются Telegram и остаются прежними.

</details>

<details>
<summary><b>Другие люди видят мой визуальный профиль?</b></summary>

Визуальные подарки, номера и юзернеймы отображаются только в этой установке VisuGram. Они не синхронизируются с другими клиентами Telegram.

</details>

<details>
<summary><b>Где хранится визуальная коллекция?</b></summary>

Для каждого аккаунта создаётся отдельный локальный JSON-файл в <code>tdata/ayu/visual/</code>. В portable-установке данные аккаунта находятся внутри <code>TelegramForcePortable</code>. При переносе клиента сохраняй portable-папку целиком.

</details>

<details>
<summary><b>Какой сейчас статус версии?</b></summary>

[Windows x64 preview 5](https://github.com/absolute-christian/VisuGram/releases/tag/visual-preview-5) успешно скомпилирована и упакована. Это экспериментальная **Debug-версия**. Вход, дарение, анимации и сохранение данных пока не проверены вручную.

</details>
