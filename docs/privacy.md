# Данные синхронизации VisuGram

**Проект политики. Перед публичным запуском нужно указать оператора сервера, контакт для обращений и конкретные сроки хранения.**

Подключённый клиент передаёт числовой Telegram ID, настоящий редактируемый Telegram-юзернейм, визуальные имена и номер, параметры подарков, комментарии, отправителей, получателей и даты. Сервер использует данные для отображения профилей, доставки визуальных подарков и проверки занятости объектов.

Видимые визуальные профили и подарки доступны другим клиентам этого сервера. Скрытые подарки отсутствуют в публичном представлении. Комментарий к видимому подарку также виден при его просмотре. Анонимность скрывает отправителя в интерфейсе и публичном представлении; оператору запись отправителя доступна.

Данные и резервные копии находятся на выбранном хостинге. Доступ к ним имеет оператор. Хостинг размещает данные и обрабатывает сетевой трафик по своим условиям. Проект не продаёт данные и не отправляет их рекламным сервисам.

Для проверки Fragment получает запрос с именем или номером и сетевой адрес сервера VisuGram. Telegram ID и комментарии туда не включаются. Публичные модели подарков клиент получает через обычный Telegram API.

Удалённое соединение требует HTTPS. API синхронизации не получает пароли, коды входа, MTProto-ключи, обычные переписки или доступ к TON-кошельку. Визуальные покупки и подарки не являются реальными переводами Telegram/TON.

Чтобы прекратить новые запросы, очистите адрес сервера в клиенте. Уже записанные данные автоматически не удаляются. Для удаления данных и резервных копий потребуется обратиться к оператору по опубликованному контакту. Оператор должен установить срок хранения и порядок удаления до публичного запуска.

Прототип доверяет Telegram ID, заявленному клиентом, и не подтверждает владение аккаунтом. Изменённый клиент способен подставить чужой ID. Эта схема не обеспечивает защищённое подтверждение личности и не предназначена для секретов, платежей или подлинных прав на активы.
