# VisuGram: визуальное дополнение к AyuGram

Изменения внесены поверх текущего исходника AyuGram. Форк опубликован как https://github.com/absolute-christian/VisuGram. Успешно собрана и опубликована [предварительная Windows x64 Debug-версия](https://github.com/absolute-christian/VisuGram/releases/tag/visual-preview-5). Инструкция: [cloud-build.md](cloud-build.md).

## Использование

1. Откройте «Мои звёзды / My Stars» и включите «Визуальные звёзды / Visual Stars» внизу списка действий. В счётчике звёзд появится ∞. При выключении возвращается настоящий баланс; локальные подарки скрываются, но сохраняются.
2. Откройте «Отправить подарок / Send a Gift» и выберите получателя. В штатном выборе получателей уже есть возможность выбрать себя. При включённом переключателе открывается визуальный каталог.
3. В штатном каталоге доступны All Gifts / Collectibles. Коллекции и цены берутся из API Telegram. В коллекции работают фильтры Model / Backdrop / Symbol, сортировки Price / Date / Number и All Listings / For Stars Only. Страницы загружаются при прокрутке. Для конкретного NFT используйте «Ссылка на NFT» и публичную ссылку t.me/nft/Название-Номер.
4. Добавьте подпись, при желании скройте имя и нажмите отправку с указанной ценой Telegram. Оплата не выполняется: подарок создаётся локально. При отправке себе открывается Избранное; при отправке другому открывается чат получателя. Используются штатное сообщение подарка и конфетти.
5. Откройте локальный подарок из сообщения или списка профиля. Свои коллекционные подарки можно закрепить рядом с аватаркой — до шести. Для своих подарков доступны скрытие и возвращение в профиль. У отправленных другому подарков этих действий нет. Удаление убирает локальную запись.
6. В «Редактировать профиль» добавлены «Визуальный номер телефона» и «Визуальные NFT-юзернеймы». Номер — свободный текст до 64 символов. Юзернеймы вводятся по одному на строку; первый основной. Допускается до 20 имён, 4–32 символа, первая буква латинская, дальше буквы, цифры и подчёркивание. Пустое поле возвращает настоящие данные. Эти настройки независимы от переключателя звёзд.

Новые надписи доступны на русском и английском. Для остальных языков используется английский вариант.

## Данные и ресурсы

Каталог использует штатные компоненты AyuGram и MTProto авторизованного клиента: payments.getStarGifts, payments.getResaleStarGifts и payments.getUniqueStarGift. Цены, фильтры и порядок выдачи определяет API Telegram; операция покупки выполняется только локально.

Ресурсы моделей и узоров загружает штатная система документов Telegram. Фоны и цвета берутся из атрибутов подарков. Карточки вне видимой области освобождаются, ресурсы сохранённых подарков обновляются по мере отображения с ограничением в два одновременных запроса. Старые локальные сочетания Visual-… сохраняются.

Визуальное дарение не вызывает оплату, передачу NFT, изменение настоящего номера или регистрацию юзернеймов. Изменения видны только в этом клиенте. Реальный баланс остаётся прежним; реальные операции Telegram продолжают работать со своим балансом.

Хранение: <рабочая папка данных клиента>/tdata/ayu/visual/<uniqueId сессии>.json. Запись атомарная; данные разделены по аккаунтам и окружениям. При выключенном режиме сохранённые TL-описания не разбираются и ресурсы подарков не запрашиваются. Сообщения восстанавливаются при открытии истории по сохранённой дате. Отключение режима убирает сообщения без удаления локальных записей.

## Карта исходников

- Telegram/SourceFiles/ayu/features/visual/visual_gifts.cpp — состояние, сохранение, создание локальных сообщений, закрепление и восстановление.
- Telegram/SourceFiles/ayu/features/visual/visual_gifts_boxes.cpp — локальная покупка, импорт NFT, дарение и редакторы профиля.
- Telegram/SourceFiles/settings/sections/settings_credits.cpp — переключатель в My Stars и бесконечный баланс.
- Telegram/SourceFiles/settings/settings_credits_graphics.cpp — отображение баланса и открытие локального подарка.
- Telegram/SourceFiles/settings/sections/settings_information.cpp — строки редактирования визуального профиля.
- Telegram/SourceFiles/info/profile/info_profile_values.cpp — визуальные номера, юзернеймы и счётчик подарков.
- Telegram/SourceFiles/info/profile/info_profile_actions.cpp — обработка ссылок визуального профиля.
- Telegram/SourceFiles/info/profile/info_profile_top_bar.cpp и data/components/recent_shared_media_gifts.cpp — закреплённые подарки возле аватарки.
- Telegram/SourceFiles/info/peer_gifts/info_peer_gifts_widget.cpp — локальные подарки в списке и защита от отправки локальных идентификаторов при сортировке.
- Telegram/SourceFiles/history/view/media/history_view_premium_gift.cpp — открытие локального подарка из сообщения.
- Telegram/SourceFiles/boxes/star_gift_box.cpp — вход в визуальный каталог и штатное превью.
- Telegram/SourceFiles/history/history.cpp — восстановление локальных подарков при загрузке истории.
- Telegram/CMakeLists.txt — подключение новых файлов.

## Проверка и передача

Выполнены статическая проверка новых файлов, сверка количества параметров и явно указанных примитивных типов TL-конструкторов, проверка используемых ключей перевода и просмотр интеграции в существующие компоненты. Изменённые проектные файлы сохранены как UTF-8 без BOM, CRLF.

Локальная сборка не запускалась согласно AGENTS.md. По отдельному запросу пользователя выполнена [успешная Windows x64 Debug-сборка в GitHub Actions](https://github.com/absolute-christian/VisuGram/actions/runs/37186824296); компиляция и линковка прошли без ошибок, ZIP упакован и опубликован в предварительном релизе. Исправленные окна подарков и значения визуального профиля проверены компилятором. Запуск интерфейса, вход в аккаунт, живые API-запросы, загрузка моделей, анимации и сохранение настроек пока не проверены вручную.

Для проверки в готовой сборке: переключить режим в обе стороны; отправить обычный и коллекционный подарок себе; проверить подпись, анонимность, Избранное и анимацию; закрепить шесть и попробовать седьмой; скрыть и удалить подарки; перезапустить клиент; проверить разделение двух аккаунтов; проверить русский/английский интерфейс; проверить ошибку загрузки и повтор; открыть обычное окно дарения до включения режима и убедиться, что последующий выбор/нажатие отправки ведёт в визуальный каталог.

visual-mode.patch содержит изменения относительно исходного снимка этой папки. visual-mode-source.zip содержит изменённые файлы и инструкцию; они уже применены в текущей рабочей папке. Исходный снимок изменённых существующих файлов сохранён в C:/Users/Home/AppData/Local/Temp/visugram-visual-originals-e8ib5enb.

Обновление каталога и отложенной загрузки требует новой сборки. Ссылка на preview 5 выше относится к предыдущей версии. Ручную проверку интерфейса выполняет пользователь.
