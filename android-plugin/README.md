# VisuGram для exteraGram

[Скачать visugram.plugin](https://raw.githubusercontent.com/absolute-christian/VisuGram/dev/android-plugin/visugram.plugin)

Отправь файл в Избранное, открой его в exteraGram и установи. Нужен SDK 1.4.0 или новее. Русский и английский уже внутри.

В настройках плагина включи **Синхронизацию**, затем открой **Визуальные подарки → Визуальные покупки**. Сервер встроен. Для подарка себе есть кнопка здесь же; другу — обычная кнопка «Подарок» в его профиле.

Версия 0.3.2 использует штатный магазин Telegram: обычные и коллекционные подарки, цены и комментарии. Получение цены и платёжной формы разрешено, а запросы списания заблокированы. Покупка отправляется на сервер VisuGram. В My Stars показывается ∞. Автоматическое улучшение и Premium пока недоступны. Выключи улучшение перед отправкой обычного подарка.

Подтверждение коллекционного подарка в визуальном режиме не требует настоящих Stars или TON. Реальный баланс не меняется; временная подмена действует только при нажатии этой кнопки, для её аккаунта и потока.

Если покупку нельзя включить, открой **Совместимость подарков** в настройках плагина. Там указаны версия клиента, SDK и конкретный недоступный метод. Отсутствие нового метода перепродажи или изменения отображения баланса больше не отключают обычные подарки; для покупки и защиты Premium есть запасные хуки окна отправки.

Полученные и отправленные подарки открываются в настройках плагина. Загружается шесть записей за раз; анимация — при просмотре. У своего коллекционного подарка можно изменить закрепление, видимость и «Носить». Эти изменения видны в VisuGram Desktop. Если получатель ещё не подключался к серверу, подарок сохраняется только локально с явным сообщением.

Визуальные юзернеймы, основной юзернейм и номера +888 редактируются здесь же. Сервер проверяет занятость. Профили других пользователей загружаются при открытии.

Это предварительная версия. Сообщения-подарки в чате, сетка подарков и украшение аватара на Android ещё переносятся. Настоящие данные Telegram остаются прежними. Если нужных Java-хуков нет, включение визуальных покупок недоступно. На телефоне версия пока не проверена.

Разработка: [документация плагинов](https://plugins.exteragram.app/docs), [исходники Telegram Android](https://github.com/DrKLO/Telegram/tree/f2908b14133bbffbf7ab04f641ecb5bfaf533242/TMessagesProj/src/main/java/org/telegram). Проверки без Android: `python -B -m unittest discover -s android-plugin/tests -v`.
