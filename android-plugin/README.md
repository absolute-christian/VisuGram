# VisuGram для exteraGram

Первая предварительная версия плагина: визуальные юзернеймы, номера +888 и общий профиль с VisuGram Desktop. Интерфейс на русском и английском.

[Скачать visugram.plugin](https://raw.githubusercontent.com/absolute-christian/VisuGram/dev/android-plugin/visugram.plugin). Отправьте файл в Избранное, откройте его в exteraGram и установите плагин. Затем включите синхронизацию в настройках VisuGram. Сервер уже встроен.

В настройках можно добавить несколько юзернеймов, выбрать визуальный основной и сохранить номер. Сервер проверяет занятость и существование номера на Fragment. Префикс +888 расположен в названии поля; вводятся только следующие цифры.

Плагин меняет текст и ссылки в существующих строках профиля, сохраняя настоящие данные Telegram. При нажатии доступны цена с Fragment и копирование. Для последней продажи используется штатное окно коллекционного объекта; для цены продажи, аукциона и визуальной цены отображается соответствующая подпись. Профили других пользователей запрашиваются только при открытии, кеш ограничен 32 профилями.

Синхронизация останавливается при сворачивании, выключении и выгрузке. Ответы относятся к конкретному аккаунту; старый ответ не применяется после переключения режима или выхода из аккаунта. Компактный ответ содержит профиль и число подарков, без TL-описаний и анимаций.

Магазин, карточки подарков, локальные сообщения и визуальные платежи пока не перенесены. Реальные платежи эта версия не перехватывает. Если Telegram не создал строку номера или юзернейма, плагин её пока не добавляет: данные остаются доступны в настройках. Совместимость Java-хуков с установленным клиентом видна в строке «Интеграция профиля»; на Android-устройстве версия ещё не проверена.

Минимальный SDK — 1.4.0; версия приложения — exteraGram 12.5.1+. Плагин использует обычные Java-хуки без нового API генерации классов. Если SDK не поддерживает многострочное поле, юзернеймы вводятся через запятую. Подробнее о движке плагинов — в [документации exteraGram](https://plugins.exteragram.app/docs). Совместимость с установленным AyuGram нужно проверить отдельно.

Проверки без Android: `python -B -m unittest discover -s android-plugin/tests -v`. Они проверяют разделение аккаунтов, остановку запросов, конфликты изменений, повтор операции и сохранность настоящих данных Telegram. Они не заменяют проверку интерфейса на телефоне.

Дальнейший перенос подарков опирается на штатные `StarsController.buyStarGift` и `buyResellingGift`: визуальная операция должна завершать их callback и не вызывать Telegram-платёж. Затем нужны адаптация TL-схемы, локальная карточка сообщения и управление подарком через `/v1/gifts*`. Публичный каталог и анимации останутся штатными, с загрузкой видимых карточек.

Java-сигнатуры проверены по [исходникам Telegram Android](https://github.com/DrKLO/Telegram/tree/f2908b14133bbffbf7ab04f641ecb5bfaf533242/TMessagesProj/src/main/java/org/telegram). Контракты Python API сверены с официальными SDK [1.4.3.10](https://github.com/exteraSquad/plugins-pysdk-builds/releases/tag/sdk-v1.4.3.10-stable-27952531946-1) и [1.4.5.7](https://github.com/exteraSquad/plugins-pysdk-builds/releases/tag/sdk-v1.4.5.7-stable-37208006129-1); ограничения старого API проверяются отдельными тестами. Это не проверка запуска на устройстве с SDK 1.4.0.
