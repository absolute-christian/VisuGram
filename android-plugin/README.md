# VisuGram для exteraGram

[Скачать visugram.plugin](https://raw.githubusercontent.com/absolute-christian/VisuGram/dev/android-plugin/visugram.plugin)

Отправь файл в Избранное, открой его в exteraGram и установи. Нужен SDK 1.4.0 или новее. Русский и английский уже внутри.

В настройках плагина включи **Синхронизацию**, затем открой **Визуальные подарки → Визуальные покупки**. Сервер встроен. Для подарка себе есть кнопка здесь же; другу — обычная кнопка «Подарок» в его профиле.

Версия 0.4.1 использует штатный магазин Telegram: обычные и коллекционные подарки, цены и комментарии. Получение цены и платёжной формы разрешено, а запросы списания заблокированы. Покупка отправляется на сервер VisuGram. В My Stars показывается ∞. Автоматическое улучшение и Premium пока недоступны. Выключи улучшение перед отправкой обычного подарка.

Подтверждение коллекционного подарка в визуальном режиме не требует настоящих Stars или TON. Реальный баланс не меняется; временная подмена действует только при нажатии этой кнопки, для её аккаунта и потока.

Если подарок не появился, открой **Совместимость подарков** на главном экране настроек плагина. Там указаны версия клиента, SDK, ошибки и сколько записей загружено и добавлено в сетку и чат. Отсутствие нового метода перепродажи или изменения отображения баланса больше не отключают обычные подарки; для покупки и защиты Premium есть запасные хуки окна отправки.

Полученные и отправленные подарки открываются в настройках плагина. Загружается шесть записей за раз; анимация — при просмотре. У своего коллекционного подарка можно изменить закрепление, видимость и «Носить». Эти изменения видны в VisuGram Desktop. Если получатель ещё не подключался к серверу, подарок сохраняется только локально с явным сообщением.

Подарки из БД добавляются в штатную сетку профиля и карточками в личные чаты. Для этого достаточно включённой синхронизации; переключатель покупок отвечает за магазин. Закрой и снова открой профиль или чат после установки обновления. Карточки сохраняют дату, Stars/TON и комментарий с премиум-эмодзи. Для Android 12.5.1 используется штатная карточка подарка с моделью NFT, названием и номером; её фон пока отличается от цветной карточки Desktop. Просмотр открывает штатное окно, управление визуальным подарком остаётся в настройках плагина.

Старые комментарии Desktop без TL-заголовка читаются вместе с премиум-эмодзи. Повреждённый или неподдерживаемый комментарий сохраняется обычным текстом. В 0.4.3 исправлено чтение Android-потока: корректные подарки и премиум-эмодзи больше не отбрасываются из-за неверного счётчика позиции `SerializedData`. Обновление профиля отложено до завершения построения экрана; неполные NFT без фона не передаются нативному интерфейсу. Визуальные подарки показывают получателя из БД и номер вместо статуса продажи. Нажатие на такой подарок у аватарки открывает визуальную запись.

История подгружается по мере загрузки обычной переписки, сетка — при прокрутке. Данные запрашиваются только для открытых экранов. Кэш ограничен восемью экранами и 120 записями на экран; более старые записи доступны через постраничный список в настройках. Подарки старше загруженного участка чата появятся при прокрутке истории. Анонимные входящие показываются в «Избранном». При отключении синхронизации добавленные элементы удаляются из экранов; настоящая переписка не записывается и не меняется.

Визуальные юзернеймы, основной юзернейм и номера +888 редактируются здесь же. Сервер проверяет занятость. Профили других пользователей загружаются при открытии.

Это предварительная версия. Украшение аватара ещё не перенесено. Настоящие данные Telegram остаются прежними. Если нужных Java-хуков нет, соответствующая интеграция недоступна; подробности есть в **Совместимость подарков**. На телефоне версия пока не проверена. `Safe mode enabled` означает блокировку импорта самим SDK, а не исходный журнал падения; VisuGram не отключает эту защиту.

Разработка: [документация плагинов](https://plugins.exteragram.app/docs), [исходники Telegram Android 12.5.1](https://github.com/DrKLO/Telegram/tree/ce8c61c47ec48a84014c8d1d0592f0e22a9dbb22/TMessagesProj/src/main/java/org/telegram). Проверки без Android: `python -B -m unittest discover -s android-plugin/tests -v`.
