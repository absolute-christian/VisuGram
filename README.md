### Installation

1. Open [Releases](https://github.com/absolute-christian/VisuGram/releases) and download the ZIP from the newest release.
2. Extract `VisuGram.exe` and the `TelegramForcePortable` folder. Put them together in the same folder.
3. Run `VisuGram.exe`.

```text
VisuGram/
├── VisuGram.exe
└── TelegramForcePortable/
```
